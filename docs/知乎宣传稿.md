## 二、正文（可直接复制）

我最近做了个小游戏，先说最离谱的一点：**你能跟农庄里的母牛求爱。**

![游戏画面](v2-village.png)
*（羊皮纸质感的地图，宙斯站在农庄里，身边是母牛、母马、母鸡和农家姑娘）*

### 这游戏到底在玩什么

你是宙斯。神力只有 100，离"众神之父"的及格线 10000 差着两个数量级——连给凡人降个雷都得精打细算。

唯一的出路很符合人设：**下凡广结良缘，让血脉遍布大地，靠子嗣给你上供神力。**

核心循环长这样：

> 探索地图 → 靠近心仪的生命 → 选择"神力注入"档位求爱 → 孕育 60 秒 → 子嗣出生 → 成长 150 秒 → 持续供给神力 → 解锁更远的大陆 → 循环

听起来像普通的放置游戏，但有两个设计让它不太一样：

**第一，注入档位是个真正的抉择。**
同样一个对象，你可以不注入（赌运气）、轻度、中度、全力。花得越多，子嗣血统越好（凡人 → 半神 → 英雄 → 神裔 → 传奇神裔），收益越高。但神力花光了，你连自己都养不起，只能干等。

**第二，赫拉在盯着你。**

![赫拉降临](hera.png)

子嗣超过 5 个后，你的正妻开始不定期下界"探亲"。地图边缘出现孔雀是预警——然后她会挑一个高品质子嗣下手：变成牛（收益砍到 40%，哞）、血统降级、或者诅咒那位母亲四个月内拒绝你。

你的选择是：花神力护佑（花钱消灾），或者忍受（子嗣遭殃）。送礼物可以安抚她降低怒气值。

**婚姻，本质上是一场资源管理。** 这是我在做这个游戏时最深的感悟。

### 关于"物种不设限"

有人问我为什么连牲畜都能结缘。

我的回答是：这恰恰是最符合宙斯的部分。希腊神话里他变过公牛、天鹅、金雨、雄鹰、甚至一团火——**在宙斯眼里，物种从来不是限制**。

所以游戏里有 52 种可结缘对象，从农家姑娘到母牛、母羊、母猪、母鸡、母鹅、母马、母驴、母犬、母猫、母兔、蜂后，再到美人鱼、凤凰、蛇发女妖、夜之女神。

![求爱面板](v2-courtship.png)
*（求爱面板：显示母亲的血统星级、注入档位、预期品质和总花费）*

而且每一位的文案我都埋了神话梗：

- 母牛：伊俄的远房表妹，低头吃草时悄悄瞄了一眼雷霆
- 母山羊：阿玛尔忒亚的后代——论辈分，她奶过幼年的宙斯
- 母熊：卡利斯托的化身……宙斯这次是带着礼物来的
- 天鹅姑娘：勒达同款——这是宙斯的老本行，驾轻就熟
- 母兔：繁殖界的传说。宙斯肃然起敬，并递上了名片

### 技术上有啥值得一说的

可能比玩法更值得同行看一眼的是实现方式：

- **零依赖、零构建、零素材**。整个游戏是 `index.html` + 几个 js 文件，双击就能玩，没有任何 npm install
- **所有画面都是 Canvas 程序化绘制**——没有一个图片素材。人物是代码一笔一笔画出来的钢笔线条，地图是程序生成的做旧羊皮纸（纸纹纤维、水渍、折痕、经纬网、罗盘玫瑰、卷轴地名）
- **音效由 Web Audio 实时合成**：雷声、金币声、赫拉降临的小三和弦下行、还有牛哞
- **LOD 分级细节**：地图上远景用简笔（不然小人糊成一团），立绘和求爱特写才渲染精修五官（眉毛、瞳孔高光、睫毛、腮红）

羊皮纸地图这块我调了好几轮才对味儿——第一版太干净像打印纸，第二版水渍太重像发霉，最后靠"纸纤维 + 极淡水渍 + 折痕 + 做旧焦边"才压住。

### 一些刻意的取舍

- **全年龄向**：所有"结缘"演出都是含蓄的卡通表达（云朵、闪电、爱心 + 一句"一段不可描述但气氛到位的神话故事"），没有任何露骨内容。毕竟这是希腊神话，重点在多子多福的经营策略，不在别的（赫拉表示赞同）
- **拒绝速通**：通关约 2~3 小时。想快也快不了——孕育和成长都要时间，繁殖成本还随子嗣数量递增
- **反速通但不劝退**：后来我把神力注入成本从 0.6 倍基础降到 0.28 倍，开局 100 神力能连求爱三四次，不至于干等

### 开源

MIT 协议，地址在这里：

**https://github.com/goufugui615-ui/zeus-path-to-godhood**

在线直接玩（不用装任何东西）：
**https://goufugui615-ui.github.io/zeus-path-to-godhood/**

想改的话很简单——所有平衡数值集中在两个文件里：
- `js/world.js`：物种图鉴（加新物种只要写三行配置）、大陆定义、地图配色
- `js/entities.js`：成本与收益公式

新增物种现在有参数化绘制器（四足 / 鸟类 / 游鱼 / 虫豸 / 蛇形），想加个"企鹅姑娘"大概十分钟。

### 最后

这个项目从一句"我想做个多子多福的游戏"开始，在 AI 协助下边做边改，中间返工过两次渲染器、修掉七八个隐蔽 bug（比如"重置存档"会被关闭页面时的自动保存写回去，等于重置无效）。

现在它还能玩、能改、能 fork。如果你玩了，欢迎回来告诉我：
