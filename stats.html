怎么接上

1. 部署 Cloudflare Worker（tools/cloudflare-worker.js），绑定一个 KV 命名空间，变量名填 ZEUS；可选加机密变量 ADMIN_KEY 当口令。
2. 打开 js/stats.js，把 mode 改成 'api'，endpoint 填 Worker 域名。
3. 把改动推到 GitHub Pages，玩家打开游戏就会自动上报。
指标含义：独立访客=按 IP 每天去重的人数；访问=打开次数；后代总数=所有玩家累计生出的子嗣数（核心指标）。
